Live flow

GLIM-25 · low-fidelity · greyscale← All flows

Pin a region and leave it. One docked popup updates in place as the text under it changes. Example: dialogue box in a fullscreen game, Spanish source, English target. Capture runs at about 2–4 fps; a block is re-read only when the pixel change passes the threshold and the region has been still for about 300 ms. Live never touches the clipboard. Keys shown for Windows; macOS in the notes.
