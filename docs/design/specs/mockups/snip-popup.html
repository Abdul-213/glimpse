Snip popup

Mockup for docs/design/specs/snip-popup.md (GLIM-30). State IDs match the spec. Popups are drawn at 1:1 over stand-in screen content. The native material can't be shown in a browser, so the 90% veil is painted over the content directly (the worst case for legibility). Fonts: this preview uses whatever system fonts are installed. CJK samples are left out because the render machine has no CJK font.
