Pinned dialogue box (interactive)

A game dialogue box is pinned at the bottom of the screen, so the popup docks above it, centred. Use Next line to simulate a settled change: only the changed block flashes, decays to the resting tint over 1.6 s, and keeps its mark until the next change. The popup's own Pause, Private and Stop buttons work; Hide popup shows the region tag. Hover a block to light its box on screen.
